ⓘ How grades are computed
Composite = the straight average of all 10 scored items — the 7 CHOICES values and the 3 Ideal Team Player virtues (Humble / Hungry / Smart), equal weight, each 1–5. Nothing else moves the number.
Grade bands: A ≥ 4.5 · B ≥ 4.0 · C < 4.0.
Flags (don't affect the number): any GWC "No" → Wrong seat · any single value ≤ 2 → Below bar · a ⬇ Worse on either Nine-More Test axis → 9-More: Worse (pre-7/30 files still carry the retired rehire "No" as Rehire No — same trigger, old label). A C grade (or any flag) puts the person on the watch list; C's are expected to carry an action plan.
Room edits (click a score in any card) never change the leader's file — they compute a separate "room read" composite that rides the room-notes export.
